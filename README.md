# franOS v2 — plan

**Start here for how it works today:** `docs/00-how-franos-works.md`

franOS v2 is Franchise Right's own franchise-recruitment system, built to replace GoHighLevel.
Written 14 November 2026 from Adam's planning session. Nothing is built yet.

**In one line:** for each brand, find the people most like its best franchisees, and the shortest path that gets them to sign, within that brand's target cost.
