- Start from `clients/<brand>/offer-and-narrative.md`. If it is not approved by Adam, stop and say so. If an asset needs something that is not in it, ask for it to be added there; do not invent it.
- Write to the avatar card: speak to the qualifiers, state the requirements up front, answer the listed objections.
- Every email has one job: move the lead to the next path step.
- Only real quotes. Every figure needs a source the fact checker can trace.
- Hand off to the review gate; never publish.
